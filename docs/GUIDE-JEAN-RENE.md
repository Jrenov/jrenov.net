# Modifier le site Jrenov — guide simple

Tu peux modifier le site toi-même, sans toucher au code : textes, coordonnées et
**photos**. Chaque modification est mise en ligne automatiquement en 1 à 2 minutes.

## 1. Se connecter

1. Va sur **https://jrenov.net/admin**
2. Clique **« Se connecter avec GitHub »** et autorise.
   *(Il faut un compte GitHub ayant accès au projet — voir avec Jules la première fois.)*

## 2. L'interface

À gauche, des **rubriques** :

| Rubrique | Ce que tu y modifies |
|---|---|
| **Coordonnées & marque** | Téléphone, e-mail, adresse, nom de l'entreprise |
| **Page d'accueil** | Titres, textes, cartes de services, FAQ, avis clients |
| **Pages de dépannage** | Plombier, Électricien, Serrurier, Débouchage : textes, FAQ **et photo** |
| **Page Rénovation** | Textes et les **photos des carrousels** (réalisations) |
| **Mentions légales** | SIRET, hébergement, date de mise à jour… |

## 3. Ajouter une photo à une page de dépannage

C'est le plus demandé. Exemple pour la page **Plombier** :

1. Rubrique **Pages de dépannage** → clique **Plombier**.
2. Trouve le champ **« Photo de la page »**.
3. Clique dessus pour **téléverser** une photo depuis ton ordinateur ou ton téléphone.
4. Remplis **« Description de la photo »** (une phrase courte qui décrit l'image,
   ex. « Réparation d'une fuite sous évier à Vannes ») — c'est utile pour Google
   et pour l'accessibilité.
5. Clique **« Save »** (en haut).
6. La photo apparaît sur la page en 1–2 minutes. ✅

> 💡 Tant qu'aucune photo n'est ajoutée, **aucun cadre vide** n'apparaît sur le
> site : l'emplacement reste simplement invisible. Tu peux donc ajouter les
> photos une par une, quand tu veux.

> 💡 Conseil photos : des images nettes, prises à l'horizontale si possible. Le
> site les optimise et les redimensionne automatiquement, pas besoin de les
> réduire toi-même.

## 4. Ajouter / changer les photos de la page Rénovation

1. Rubrique **Page Rénovation**.
2. Section **« Réalisations (3 blocs) »** → ouvre le bloc voulu (Plomberie,
   Intérieur ou Extérieur).
3. Dans **« Photos du carrousel »**, clique **« Add Photo »**, téléverse l'image
   et donne-lui une **légende**.
4. **Save**.

## 5. Modifier un texte

1. Clique une rubrique → l'élément à modifier.
2. Change le texte. Pour les champs avec une barre de mise en forme, tu peux
   mettre des mots **en gras** ou ajouter un lien (boutons au-dessus du champ).
3. **Save**. En ligne 1–2 minutes après.

## 6. Ajouter / supprimer / réorganiser

- Les listes (FAQ, avis, interventions, photos…) ont un bouton **« + »** pour
  ajouter et une **croix** pour supprimer, ainsi que des **poignées** pour
  changer l'ordre.

## Bon à savoir

- Tout est **sauvegardé et réversible** : on peut toujours revenir en arrière.
- **Le numéro de téléphone** apparaît à beaucoup d'endroits (bouton d'appel,
  Google…). Si tu le changes dans **Coordonnées & marque**, tout se met à jour au
  prochain build — mais préviens Jules pour vérifier les fiches Google.
- Certains champs techniques (identifiants d'URL, « type de service »…) ne sont
  pas affichés exprès : n'y touche pas, ils font fonctionner le site.
- En cas de doute, demande à Jules avant de supprimer quelque chose d'important.
